# Sistemas-Operativos-VG-III
Simulador de planificación de CPU y gestión de memoria desarrollado en Python con Tkinter para la materia Sistemas Operativos (2025). Implementa SRTF, particiones fijas con Best-Fit y swapping. Permite cargar procesos desde CSV, seguir su ejecución paso a paso y consultar un resumen final con métricas por proceso y rendimiento general.
